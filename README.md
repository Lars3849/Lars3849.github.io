# Lars3849.github.io
Persoonlijke website van Lars Tjalsma, live op https://larstjalsma.dev.

Handgeschreven HTML en CSS, zonder framework of build-stap.

| Pagina | Inhoud |
| --- | --- |
| `index.html` | Home |
| `projecten.html` | Overzicht van alle projecten |
| `puzzelspel.html` | Project Game Interaction (WPF, C#) |
| `slaapomgevingsmeter.html` | Project Internet of Things (Arduino, MQTT) |
| `opleiding.html` | Opleiding, periodes en vakken |
| `over-mij.html` | Profiel, werk, vaardigheden en contact |

Elke pagina heeft dezelfde header en footer; pas die bij een wijziging op alle pagina's aan.
Afbeeldingen staan in `img/`, de stijl in `style.css`.
